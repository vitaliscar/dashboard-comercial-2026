---
name: UX prototyping to production
description: Durable guidance for carrying the CCV visual direction from isolated prototypes into the dashboard.
---

For broad CCV UI changes, validate the executive and operations surfaces in the isolated mockup sandbox, then compare the real application routes at desktop and mobile sizes before considering the graduation complete.

**Why:** Applying only the color tokens initially left the key routes structurally generic; route-level screenshots caught the gap before delivery.

**How to apply:** Keep the palette, hierarchy, action-first states, demo-data labeling, and responsive behavior aligned across the shell, executive summary, funnel, and collections views.
