## Dirección visual

Interfaz de trabajo comercial para dirección y equipos de venta. Lenguaje minimalista de producto, compacto y legible. ENERGY 1 / RHYTHM 1 / MOTION 1. Una jerarquía uniforme facilita comparar datos; las variaciones de color se reservan para series, estados y selección.

- Superficies blancas y gris neutro muy claro; texto carbón. Un acento índigo/cobalto para acciones y selección.
- Gráficos con paleta diferenciada y etiquetas: azul, verde, ámbar, violeta y rojo. El color no será la única explicación del estado.
- Inter local para interfaz; cifras tabulares. Tipografía monoespaciada se limita a la pila del sistema para cifras/código.
- Títulos de página 20–24 px; métricas 28–34 px; texto 13–14 px. Evitar títulos gigantes, serif y etiquetas espaciadas decorativas.
- Bordes suaves, radios 6–8 px, sombras solo en elementos flotantes. Espaciado de trabajo de 16–24 px.
